# Enterprise System Design

Transform a product idea or scaling problem into a complete system design. Supports FAANG interview mode and enterprise production mode. Every decision documented with trade-offs.

## Quick Start

When the user says "design [system]", gather requirements:
1. Problem statement?
2. Scale requirements? (users, traffic, data volume?)
3. Constraints? (budget, timeline, tech stack?)
4. Interview or production mode?

## Usage

```
Design a URL shortener
Design WhatsApp
Design Uber
Design a payment gateway
Generate HLD for a banking system
Compare architecture options
```
