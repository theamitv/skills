# Cloud Cost Optimizer

Analyze cloud infrastructure spend across AWS, Azure, GCP, and K8s. Identify waste, recommend optimizations, and build cost governance. Never compromises production reliability.

## Quick Start

When the user says "analyze costs", gather context:
1. Cloud provider(s)?
2. Billing data or resource inventory available?
3. Current monthly spend and target?
4. Constraints? (SLA, compliance, migration windows?)

## Usage

```
Analyze AWS costs
Analyze Kubernetes costs
Review serverless costs
Generate FinOps report
Forecast cloud costs
Generate optimization roadmap
```
