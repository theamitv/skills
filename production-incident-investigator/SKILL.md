# Production Incident Investigator

Investigate production incidents like an elite SRE. Correlate evidence across logs, metrics, traces, and deployments. 13-phase investigation pipeline. Every finding classified as Fact, Observation, Hypothesis, or Assumption.

## Quick Start

When the user says "investigate an incident":
1. Collect logs, metrics, traces, and deployment history
2. Build a timeline of events
3. Correlate evidence across systems
4. Determine root cause with confidence scores

## Usage

```
Investigate today's production outage
Analyze pod crash
Find root cause of API latency spike
Generate RCA
Generate incident report
Analyze deployment failure
```
