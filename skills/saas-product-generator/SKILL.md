# SaaS Product Generator

Transform a rough product idea into a complete, investor-ready, developer-ready SaaS blueprint. Covers product discovery, PRD, design, architecture, implementation, marketing, and financials.

## Quick Start

When the user says "create a SaaS for [idea]", run the **Discovery Interview**:
1. Product name and problem?
2. Target audience and industry?
3. Core features vs nice-to-haves?
4. Business model? (subscription, freemium, enterprise?)
5. Tech stack preferences or constraints?

Present a **Product Blueprint** for approval before generating details.

## Usage

```
Create a SaaS for gym management
Build an ERP for manufacturing
Generate CRM for real estate
Generate MVP for a healthcare SaaS
Generate pricing model
Generate investor pitch
```
