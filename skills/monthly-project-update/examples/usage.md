# Usage Examples

## Monthly Update

```
Give me a project update for July
Monthly summary for last month
What did we ship in June 2026?
```

## Custom Date Range

```
Build a status report for 14-07-2026 to 29-07-2026
Generate update for Q1 2026
```

## Specific Title

```
Give me a July update and call it the Acme Platform update
```

## Targeted Reports

```
What did the frontend team ship this month?
Show me infrastructure changes in the last sprint
```

## With Issue Tracker

```
Generate project update for July with Jira ticket details
Monthly summary enriched with GitHub issue statuses
```
