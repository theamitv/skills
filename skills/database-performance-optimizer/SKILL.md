# Database Performance Optimizer

Analyze relational and NoSQL databases to find bottlenecks. Schema review, query optimization, index analysis, execution plan interpretation, transaction analysis, and capacity planning. Data integrity first.

## Quick Start

When the user says "analyze database", gather context:
1. Database type? (PostgreSQL, MySQL, MongoDB, DynamoDB?)
2. Schema, queries, or execution plans available?
3. Symptom? (slow queries, high CPU, connection issues?)
4. Scale? (data size, QPS, concurrent connections?)

## Usage

```
Analyze database performance
Explain this slow query
Suggest indexes
Review schema
Analyze execution plan
Generate optimization roadmap
```
