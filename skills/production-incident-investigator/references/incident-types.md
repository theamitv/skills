# Incident Types Reference

## Kubernetes Incidents
- CrashLoopBackOff, OOMKilled, ImagePullBackOff, Eviction
- Node pressure, resource exhaustion, taints/tolerations
- Network policy misconfiguration, service mesh failures

## Application Incidents
- Memory leaks, CPU spikes, goroutine/thread leaks
- Deadlocks, race conditions, concurrency bugs
- Configuration drift, feature flag issues

## Database Incidents
- Deadlocks, lock contention, transaction log full
- Replication lag, failover issues, connection pool exhaustion
- Slow queries, missing indexes, full table scans

## Network Incidents
- DNS resolution failures, TLS certificate expiry
- Load balancer misconfiguration, firewall rule changes
- DDoS, rate limiting, bandwidth saturation

## Cloud Incidents
- IAM misconfiguration, credential rotation failures
- Autoscaling failures, capacity limits
- Region/zone outages, cross-region latency
